# PIXEL BRAWL — одиночная версия

Это стартовый интерфейс Telegram Mini App. В этой версии нет PvP, матчмейкинга или подключения к другим игрокам.

## Что включено
- Главная страница с персонажем Байтом.
- Демонстрационный одиночный бой против компьютерного противника.
- Магазин скинов для одного персонажа.
- Профиль и базовый прогресс.
- Подключение Telegram WebApp SDK.

## Запуск
Для Telegram Mini App страницу нужно разместить на HTTPS-хостинге, затем указать URL в настройках бота через BotFather.

Для локальной проверки можно открыть `index.html` в браузере. Telegram-данные профиля будут доступны только внутри Telegram.

## Важно: чего пока нет
- Бой сейчас демонстрационный: простая логика кнопки, а не полноценная игровая арена.
- Прогресс хранится только в оперативном состоянии страницы и сбрасывается после перезагрузки.
- Кнопки магазина пока не проводят оплату.
- Для реальных Telegram Stars нужен сервер: он должен создавать invoice link, обрабатывать `pre_checkout_query` и `successful_payment`, проверять платёж и выдавать скин только после подтверждения.
- Не помещайте токен Telegram-бота в `app.js` или другие публичные файлы сайта.

Сначала можно развернуть эту версию как прототип, а затем постепенно добавить настоящую игровую механику и серверное сохранение.
